# 한국어 사용자 화면 문구

이 경로의 화면 문구는 한국어다. 정확한 표기 값(어미 선택 · 날짜 · 금액 · 전화번호 형식 · 최소 크기)은
`.claude/harness.profile.md` 에 있고, 여기에는 그 값을 일관되게 쓰는 방법만 둔다.

## 적용 대상 · 제외

- 적용 — 프로젝트가 `.claude/standards.json` 에서 고른, 사용자에게 보이는 한국어 화면 코드 경로
- 제외 — 개발자 도구의 코드 식별자 · 로그 · 테스트 이름, 한국어가 아닌 locale 화면

## 문체와 형식

- 한 화면 · 한 흐름 안에서 어미를 섞지 않는다. 어느 어미를 쓰는지는 profile 이 정한다
- 날짜 · 금액 · 전화번호 같은 형식은 profile 에 정한 한 가지만 쓴다. 화면마다 따로 만들지 않는다
- 내부 코드 · enum 값 · 개발 용어를 그대로 화면에 내보내지 않는다. 표시 문구로 바꾸는 한 곳을 둔다

## 긴 문자열

한국어는 같은 뜻의 영어보다 길고 줄바꿈 규칙이 다르다.

- 버튼 라벨 · 탭 · 제목 · 표 머리글에서 줄바꿈과 말줄임을 바꿀 때마다 확인한다
- 어절 중간이 끊기지 않게 하는 방식과 좁은 화면 기준은 프로젝트 기준을 따른다
- 확인하지 못한 화면 폭 · 기기는 미검증으로 보고한다
