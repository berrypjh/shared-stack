# 플랫폼별 확인 방법

무엇이 옳은지는 저장소 rule 과 패키지 `AGENTS.md` 가 정한다. 이 문서는 **그것을 어떻게 확인하는지**만 다룬다.
각 항목에 확인 방식을 붙였다 — **판독**(코드를 읽음) · **자동**(테스트 · 규칙 검사) · **실제**(렌더 · 조작 · 보조 기술).
검색 명령의 `<src>` 는 검수 범위의 경로다. 검색 결과는 후보이고, 걸리지 않았다고 준수가 확정되지 않는다.

## Web

### 의미 구조

- 새 영역이 맞는 요소인가 — `header` · `nav` · `main` · `aside` · `section` · 목록 · `form` — **판독**
- 랜드마크가 중복되지 않고 제목 단계가 건너뛰지 않는가 — **판독**, 렌더 결과의 접근성 트리로 **자동**
- 누를 수 있는 것이 `button` · `a` 인가. 클릭 핸들러가 붙은 일반 요소가 없는가 — **판독**

  ```bash
  grep -rn 'onClick' <src> | grep -vE '<button|<a '
  ```

- 아이콘만 있는 컨트롤에 접근 가능한 이름이 있는가 — **판독**, 역할 · 이름으로 찾는 테스트로 **자동**

### 키보드와 포커스

- 마우스로만 되는 동작이 없는가. 열기 · 닫기 · 선택이 키보드로 되는가 — **실제**(Tab · Enter · Space · Esc 로 이동)
- 포커스 표시를 지우지 않았는가 — **판독**

  ```bash
  grep -rnE 'outline-none|outline: *none' <src>
  ```

- 대화상자 · 시트 · 팝오버가 포커스를 가두고, 닫으면 원래 자리로 돌려주는가 — **자동**(가능하면), **실제**
- OS 고대비 · 강제 색 모드에서도 포커스와 경계가 보이는가 — **실제**

### 반응형과 긴 문자열

- profile 이 정한 폭에서 가로 스크롤 · 잘림이 없는가. 폭 기준이 없으면 기준 없음으로 보고 — **실제**
- 긴 문자열에서 줄바꿈 · 말줄임이 의도대로인가 — 스토리 · 테스트에 긴 값을 넣어 **자동** 또는 **실제**
- 고정 폭을 새로 넣지 않았는가 — **판독**

### 런타임

- 서버 렌더링이 있으면 서버에서 도는 코드가 browser API 를 쓰지 않는가 — **판독**, build 로 **자동**
- 소스에 디버그 출력이 남지 않았는가 — **판독**

  ```bash
  grep -rn 'console\.' <src>
  ```

## React Native

### 보조 기술

- 누를 수 있는 것에 `accessibilityRole` 이 있는가 — **판독**, 역할로 찾는 테스트로 **자동**
- 선택 · 비활성 같은 상태를 `accessibilityState` 로 알리는가 — **판독** · **자동**
- 아이콘만 있는 버튼 · 이미지에 locale 에 맞는 `accessibilityLabel` 이 있는가, 장식 요소는 읽히지 않는가 — **판독**
- 실제로 읽히는 순서와 문장 — **실제**(VoiceOver · TalkBack)

### 상호작용

- 누를 수 있는 영역이 profile 의 최소 터치 크기를 넘는가. 시각 크기와 히트 영역을 따로 본다 — **판독**, 실기기 **실제**
- 입력이 있으면 키보드가 입력창을 가리지 않는가. iOS · Android 동작이 다르다 — **실제**
- 늘어날 수 있는 목록이 가상화 목록인가. 스크롤 안에 같은 방향 스크롤을 중첩하지 않았는가 — **판독**
- 목록 항목의 key 가 안정적인가(인덱스 아님) — **판독**

### 화면 가장자리

- safe area · status bar 는 프로젝트 셸이 한 곳에서 다룬다(profile). 화면마다 다시 두지 않았는가 — **판독**, 실기기 **실제**

### iOS 와 Android

한쪽만 보고 완료로 보고하지 않는다. 자주 갈라지는 곳 — 그림자(`shadow*` 와 `elevation`) · 키보드 회피 방식 ·
눌림 피드백 · 같은 글자 크기의 줄 높이 · 하단 제스처 영역. 모두 **실제** 확인이 필요하다.
