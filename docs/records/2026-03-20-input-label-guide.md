# 보이는 라벨 — 컨트롤과 명시적으로 잇고, placeholder 로 대신하지 않음

react-ui `InputLabel` 을 만들며 보이는 라벨의 기준을 정함. 라벨은 문맥 없이도 목적을 알 수 있게 쓰고, 컨트롤과 코드로 연결함.

## 상황

- 입력마다 라벨이 필요하고, 라벨이 보이기만 하고 컨트롤과 이어지지 않으면 스크린 리더는 입력의 이름을 알 수 없음
- 라벨을 제대로 이으면 라벨을 눌러도 컨트롤이 선택되어 클릭 영역이 커짐 — 운동 장애 사용자에게 유리

## 판단

라벨은 보이게, 컨트롤과는 코드로 이음.

| 판단                          | 내용                                                                                           |
| ----------------------------- | ---------------------------------------------------------------------------------------------- |
| **문맥 없이도 이해되는 라벨** | 같은 기능은 같은 용어로. 지시문 · 단어형을 섞지 않고 한 가지 스타일                            |
| **명시적 연결이 기본**        | `label[for]` ↔ `input[id]`. 페이지 안의 인터랙티브 요소는 유일한 id                           |
| **감싸기는 예외**             | `for` · `id` 로 잇기 어려울 때 `<label>텍스트 <input /></label>` 로 감쌈                       |
| **위치**                      | 라디오 · 체크박스는 라벨이 오른쪽, 텍스트 · 선택 입력은 왼쪽이나 위                            |
| **라벨로 쓰지 않는 것**       | placeholder(입력하면 사라지고 대비가 낮음), 개별 컨트롤에 쓰는 legend, 여러 컨트롤을 묶는 라벨 |

## 반영

- **`InputLabel`** — native `<label>` 을 그림
- **명시적 연결** — `TextField` 가 `useId` 로 id 를 만들어 `InputLabel` 의 `htmlFor` 와 입력의 `id` 로 잇음. `id` prop 을 주면 그 값을 씀
- **감싸기** — `Checkbox` · `Radio` 는 `<label>` 이 native `<input>` 을 감싸고 글자를 입력 뒤에 둠. 라벨이 오른쪽에 서고, 라벨을 눌러도 토글됨
- **placeholder 는 따로** — `TextField` 의 `placeholder` 는 입력에만 가고, 입력의 이름은 `label` 이 줌

## 검증

- `TextField.test.tsx` — label 이 입력의 accessible name 이 되고, `id` 를 주면 label `htmlFor` 와 input `id` 가 이어짐
